# Security Policy

Please do not disclose security vulnerabilities in public issues. Report suspected vulnerabilities privately through the repository owner’s GitHub contact mechanisms and include a concise description, affected files or versions, reproduction steps that do not harm third-party systems, and potential impact.

Do not submit credentials, private keys, personal data, exploit payloads, or access to systems you do not own or have explicit permission to assess. Security reports will be reviewed on a best-effort basis.
