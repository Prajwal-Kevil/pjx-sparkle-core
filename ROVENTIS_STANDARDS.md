# Roventis Technologies repository standards

This repository is part of the **Roventis Technologies** software portfolio and is maintained by **Prajwal C**.

## Professional standards

- Keep the README accurate, concise, and useful to a new contributor.
- Document prerequisites, setup, common commands, and known limitations when they apply.
- Keep secrets, credentials, personal data, and customer material out of commits.
- Use only systems, accounts, data, and networks that you own or are explicitly authorized to assess.
- Prefer small, reviewable changes with tests or a clear verification step.
- Preserve upstream attribution and the repository's existing license terms.

## Scope and safety

This project must not be used to bypass access controls, disrupt services, process real payment-card data, collect private information, or impersonate people. Security research and automation are limited to controlled, authorized environments.

## Licensing

Existing license files and third-party notices are authoritative. This standardization pass does not add or change a license.
